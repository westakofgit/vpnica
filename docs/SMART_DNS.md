# Smart DNS

Модуль пока намеренно не включён в базовый запуск: для безопасного DoH/DoT, сертификата и бесшовной миграции нужен собственный домен.

Планируемый модуль состоит из:

- защищённого DNS-резолвера;
- ограниченного списка доменов, обслуживаемых SNI-релеем;
- ночного получения данных с iplist.opencck.org;
- ручных списков `proxy` и `direct`;
- атомарного применения обновления;
- хранения последней рабочей версии и отката;
- ограничения запросов, чтобы сервер не стал открытым публичным резолвером.

До появления домена не следует публиковать DNS-порт наружу и выпускать мобильные DNS-профили на голый IP.
