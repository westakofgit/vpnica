# Добавление нового протокола

Новый транспорт добавляется отдельным Compose-файлом `compose.<protocol>.yaml` и не изменяет базовый `compose.yaml`.

Для каждого модуля необходимо определить:

1. закреплённый образ и его digest;
2. TCP/UDP-порты и возможные конфликты;
3. отдельную папку `state/<protocol>/`;
4. способ выпуска и отзыва клиентского профиля;
5. файлы, которые входят в зашифрованный бэкап;
6. порядок миграции без изменения профилей;
7. минимальные Linux capabilities вместо privileged-режима.

Если транспорт использует обычный TLS с SNI, впоследствии его можно поместить за общим TCP-маршрутизатором. Сырые TCP-протоколы получают отдельный порт, UDP-протоколы — отдельный UDP-порт.
