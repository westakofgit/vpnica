# Перенос на другой VPS

## Подготовка

1. На старом сервере создать зашифрованную копию командой `sudo vpnica backup`.
2. Скопировать проект и архив на новый сервер.
3. На новом сервере из папки проекта выполнить:

   `sudo ./install.sh --restore /путь/vpnica-backup.tar.gz.enc --host node.example.com`

Если домена ещё нет, вместо него можно указать `--host auto`. Установщик восстановит OpenVPN PKI, secret Telemt, ручные маршруты и сформирует новые файлы подключения для указанного адреса.

## Переключение

1. Запустить контейнеры на новом сервере.
2. При использовании домена заменить его A-запись на новый IPv4.
3. Старый VPS оставить включённым минимум на время TTL DNS.
4. После завершения перехода удалить старый сервер у хостера.

При сохранении OpenVPN PKI и секретов новые сертификаты выпускать не требуется. Если используется домен, достаточно изменить его A-запись. Если в профилях указан IP, после переезда нужно заменить адрес сервера в OpenVPN-профилях и заново создать ссылки Telemt.

## Что не переносится

- журналы контейнеров;
- скачанные образы;
- временный кэш Telemt;
